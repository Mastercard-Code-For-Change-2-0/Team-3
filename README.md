🔐 Secure Student Profile Management System

A secure web application built with the MERN Stack (MongoDB, Express.js, React.js, Node.js) for managing student profiles.
The system ensures data privacy, role-based access, and efficient management of student records.

🚀 Features

User Roles

👨‍🎓 Student → Manage personal details, update profile, view progress.

🧑‍💼 Clerical Staff → Add/update student records, handle academic data.

🛡️ Admin → Full access, manage users, view analytics, apply filters.

Authentication & Security

JWT-based authentication

Bcrypt password hashing

Role-based authorization

Data Management

CRUD operations for student profiles

Filtering & searching student data

Secure storage using MongoDB

Analytics (Optional Enhancements)

📊 Dashboards with Recharts/Chart.js

📈 Track student growth and performance

🛠️ Tech Stack

Frontend: React.js, Tailwind CSS

Backend: Node.js, Express.js

Database: MongoDB

Authentication: JWT, Bcrypt
